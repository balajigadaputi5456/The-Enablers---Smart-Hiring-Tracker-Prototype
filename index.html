Core AI capability 01

Semantic resume intelligence

Evaluate candidate-role fit using context, equivalent technologies, transferable experience and evidence—not exact keyword overlap alone.

CORE MVP
Core capability: This is a foundational part of Smart Hiring Tracker. The match output is decision support: recruiters review the evidence, validate gaps and make the shortlist decision.
Sample output only; no external AI model is called in this standalone HTML.

Evidence by role criterion
Python programming MatchedResume evidence: Python used in ML workflow and data processing projects.
Machine learning MatchedResume evidence: model development and evaluation experience.
Cloud deployment ValidateProduction deployment evidence is not sufficiently clear in the sample CV.
Contextual skill interpretation
Equivalent technologiesRecognise related tools and frameworks when they demonstrate the same underlying capability—for example, PyTorch and TensorFlow for machine-learning frameworks.
Transferable experienceConsider relevant work across adjacent domains, comparable projects and reusable technical skills, subject to recruiter validation.
Skill gaps and uncertaintyHighlight missing or weakly evidenced criteria instead of treating an absent keyword as automatic proof that a skill is missing.
A production scoring model needs validated role criteria, representative data, bias checks, score calibration and ongoing monitoring. The displayed score and evidence are illustrative.

ExperienceRelevant responsibilities, project depth and duration
ContextEquivalent technologies and transferable experience
QualificationsEducation, certifications and eligibility requirements
EvidenceSource snippets and references from the candidate profile
GapsMissing, partial or uncertain criteria to validate
Core AI capability 02

Historical talent rediscovery

Search previously received candidate profiles against a newly opened role, including candidates who were not selected earlier or were kept on hold.

CORE MVP
Core capability: Candidate rediscovery searches the organisation's authorised historical candidate pool. It retains prior role, stage, source, referrer and outcome history so recruiters can re-evaluate candidates in a new context.

How the platform manages interview evaluation
1. Interview assignedFeedback form is automatically made available to the assigned interviewer.
2. Structured evaluationRole-specific criteria and rating fields are preloaded.
3. Voice-to-text optionInterviewer may dictate observations; transcript requires review.
